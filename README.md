# enshrouded-proton

Docker image for an Enshrouded dedicated server on Pterodactyl/Wings: Debian trixie, GE-Proton11-9 (pinned, sha512-verified), Vulkan, FreeType amd64/i386, Xvfb.

Based on `steamcmd/proton` from [Ptero-Eggs/yolks](https://github.com/Ptero-Eggs/yolks) (MIT, see LICENSE.md).

Image: `ghcr.io/dvkei/enshrouded-proton:latest` (also `:ge-proton11-9`).

Full guide (startup command, checks, troubleshooting): [ENSHROUDED_DOCKER_GITHUB.md](ENSHROUDED_DOCKER_GITHUB.md).
